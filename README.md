# Fantazma Marigold Memorial

Eres un diseñador UX/UI y desarrollador web senior frontend con experiencia en desarrollo en páginas creativas

TAREA: Crea una landing page para hacer un altar digital para mi mascota, la cual es un perrito y se llama fantazma  CONTEXTO:

Las caracteristicas de la landing page son: -Paleta de colores tradicional:morado, naranja, flores de sempasuchil . -que sea interactiva al momento de pasar el cursor por algun detalle se agrande -petalos de cempasúchil cayendo -que inicie a enseñar la web al apretar la nariz de un perro como botón. -La foto de mi perrito (yo te la voy a proporcionar). -un arco de flores de cemapsuchitl -Guirnalda de papel picado animada en el encabezado. -veladoras con una foto del perrito -Que el cursor sea en forma de huella y que sea tradicional mexica en el mictlan
